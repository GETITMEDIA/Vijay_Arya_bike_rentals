Tw Cen MT — website font files
==============================

TwCenMT-Regular.ttf   → normal text  (from Tw Cen MT, TCM_____.TTF)
TwCenMT-Bold.ttf      → headings and buttons (TCB_____.TTF)
TwCenMT-Italic.ttf    → italic text  (TCMI____.TTF)

These are copies of the Tw Cen MT fonts installed with Microsoft Office on
this computer. The site loads them through @font-face in css/style.css, so
every visitor sees the same typeface, whatever device they use.

If you buy "Tw Cen MT Std Semibold" from Monotype, drop the .woff2/.ttf in
this folder and point the @font-face `src` at it — nothing else changes.

Licence note: Tw Cen MT ships with Microsoft Office for use on this machine.
Serving it from a public website is a separate licence. Before the site goes
live, either buy a web licence from Monotype (monotype.com / myfonts.com)
or keep the free fallback (Jost), which looks very close.
